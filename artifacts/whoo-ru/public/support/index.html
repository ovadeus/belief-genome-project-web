Getting Started

Getting Started

Overview of BGP Mission Control

BGP Mission Control is the desktop companion app for the Belief Genome Project. It serves as your personal intelligence hub — combining AI-powered agents, a research feed, email management, media transcription, and the Belief Genome system into one unified dashboard.

The app is built on Electron and runs natively on macOS. Key features include:

  • Dashboard — A customizable home screen with widgets, background photos/videos, and an idle-fade feature that reveals your wallpaper after 30 seconds of inactivity.
  • Agents — AI-powered automations that handle tasks like email summarization, research, text-to-speech, transcription, and file organization.
  • Brain — A persistent memory layer that stores context from agent runs, reflections, and interactions.
  • Media Library — A centralized library for transcripts, generated audio, and other media produced by agents.
  • Belief Genome — A self-reflection framework that maps your beliefs across multiple dimensions using probes and confidence scoring.
  • Research Feed — Curated research summaries based on your interests and passions.
Installation Guide (macOS)

System Requirements

  • macOS 12 (Monterey) or later
  • At least 500 MB of free disk space
  • An internet connection for API-powered features

Installation Steps

  1. Download the latest .dmg installer from the official BGP website or your provided distribution link.
  2. Double-click the .dmg file to mount it.
  3. Drag BGP Mission Control into your Applications folder.
  4. Eject the disk image and launch the app from Applications or Spotlight.
Gatekeeper Notice
On first launch, macOS may display a warning that the app is from an unidentified developer. Go to System Settings > Privacy & Security and click "Open Anyway" to authorize the app.
What to Expect on First Launch

When you first open Mission Control, you will see the Dashboard with default widgets and a background image. Here is what to do next:

  1. Open Settings — Click the gear icon in the top-right corner of the dashboard.
  2. Add your API keys — Most agents require at least a Claude (Anthropic) API key. See the API Keys section for details on which keys unlock which features.
  3. Connect Gmail (optional) — If you want email summarization and the Daily Planner, connect your Gmail account via OAuth.
  4. Explore Agents — Visit the Agents Library page from the sidebar to see all available agents, enable or disable them, and run your first automation.
  5. Customize your Dashboard — Set a background photo, rearrange widgets, and make the space yours.
Tip
The app stores all data locally on your machine in the Electron userData directory. No data is sent to BGP servers — API calls go directly to the respective providers (Anthropic, OpenAI, ElevenLabs, Google).
Configuration

API Keys & Integrations

Overview of API Keys

Mission Control connects to third-party AI services via API keys that you provide. Your keys are stored locally on your machine and are never shared with BGP.

Which key unlocks what?

  • Claude (Anthropic) — Required for most agents: Research Pulse, Daily Planner, Gmail Summary, Probe Generator, and PDF OCR fallback. This is the primary AI engine.
  • OpenAI — Required for Audio Transcription (Whisper API). Also used as a fallback for YouTube transcription when captions are unavailable.
  • ElevenLabs — Required for the Text to Speech agent. Converts text into high-quality MP3 audio.
  • Gmail (OAuth) — Required for Gmail Summary, Daily Planner, and Inbox Audit agents. Uses Google OAuth so your password is never stored.
Note
You do not need all keys to use the app. Start with just a Claude API key and add others as you need specific features.
Setting Up Claude (Anthropic) API Key
  1. Go to console.anthropic.com and sign in or create an account.
  2. Navigate to API Keys in the left sidebar.
  3. Click "Create Key", give it a name (e.g., "Mission Control"), and copy the key. It starts with sk-ant-.
  4. In Mission Control, open Settings (gear icon) and find the AI Models section.
  5. Paste the key into the Claude API Key field and click Save.
Important
Anthropic requires a credit balance or active billing plan. New accounts often receive a small free credit, but you will need to add a payment method for continued use.
Setting Up ElevenLabs API Key
  1. Go to elevenlabs.io and sign in or create a free account.
  2. Click your profile icon in the bottom-left corner and select "Profile + API key".
  3. Copy your API key (or generate a new one).
  4. In Mission Control, open Settings and find the Media & Generation APIs section.
  5. Paste the key into the ElevenLabs API Key field and click Save.

The free tier includes a limited number of characters per month. See Credits & Quotas for details on limits.

Setting Up OpenAI API Key
  1. Go to platform.openai.com and sign in.
  2. Navigate to API Keys under your profile menu.
  3. Click "Create new secret key" and copy it. It starts with sk-.
  4. In Mission Control, open Settings and find the AI Models section.
  5. Paste the key into the OpenAI API Key field and click Save.

The OpenAI key is used exclusively for Whisper-based audio transcription and as a YouTube transcription fallback. You will not incur GPT chat charges from Mission Control.

Connecting Gmail

Mission Control uses Google OAuth 2.0 to access your Gmail. This means you sign in through Google's official login page — Mission Control never sees or stores your password.

  1. Open Settings and scroll to the Gmail section.
  2. Click "Connect Gmail Account". A browser window will open to Google's sign-in page.
  3. Sign in with the Google account you want to connect and grant the requested permissions (read-only access to messages).
  4. Once authorized, the window will close and your account will appear as connected in Settings.
Tip
You can connect multiple Gmail accounts. The Gmail Summary and Daily Planner agents will pull from all connected accounts.
Audio Generation

ElevenLabs / Text to MP3

Understanding ElevenLabs Credits & Quotas

ElevenLabs uses a character-based credit system. Each plan gives you a monthly allotment of characters that resets on your billing date.

How characters are counted

  • Every character in your input text counts — letters, spaces, punctuation, line breaks.
  • A typical page of text is roughly 2,000–3,000 characters.
  • Mission Control uses the eleven_multilingual_v2 model, which may consume slightly more credits than the basic English-only model on some plans.

Checking your usage

Log in to elevenlabs.io and check the usage meter in your profile. It shows remaining characters for the current billing cycle.

"Request exceeds API key quota" Error

This is the most common support issue with Mission Control's Text to Speech feature. The error message can be confusing because ElevenLabs has two separate layers of limits:

1. Account-Level Credits (monthly character allowance)

This is the total number of characters your ElevenLabs plan allows per month. If you are on the free tier, this is typically 10,000 characters/month. When depleted, all API keys on the account stop working until the cycle resets or you upgrade.

2. Per-API-Key Quotas (individual key limits)

Each API key can have its own quota limit that is separate from and lower than your account credits. This is the part that catches most users off guard.

The #1 Confusion

You can have 5,000 account credits remaining but still get a quota error if your specific API key has been assigned a lower limit (e.g., 500 characters). ElevenLabs lets you create multiple API keys with different quotas for different apps — the per-key limit is enforced before the account limit is checked.

How to fix this

  1. Log in to elevenlabs.io and go to Profile + API key.
  2. Find the API key you are using in Mission Control.
  3. Check if the key has a custom quota or rate limit set. If so, increase it or remove the limit.
  4. Also check the account-level usage meter to make sure you have not exhausted your monthly allowance.
  5. If your monthly credits are depleted, either wait for the billing cycle to reset or upgrade your plan.

Quick diagnostic

  • Error appears on very short text (under 100 chars)? → Almost certainly a per-key quota issue, not an account credit issue.
  • Error appears only on long text? → You may be near the end of your monthly credits. Check account usage.
  • Worked yesterday, not today? → Monthly credits may have reset to a lower amount, or per-key quota was recently changed.
ElevenLabs Pricing Plans

ElevenLabs offers several tiers. Approximate character limits as of early 2026:

  • Free — ~10,000 characters/month. Limited voice selection. Good for trying things out.
  • Starter ($5/mo) — ~30,000 characters/month. Access to more voices and voice cloning.
  • Creator ($22/mo) — ~100,000 characters/month. Professional voice cloning, higher quality.
  • Pro ($99/mo) — ~500,000 characters/month. Priority processing, all features.
  • Scale ($330/mo) — ~2,000,000 characters/month. Enterprise features.
Note
Prices and limits change frequently. Visit elevenlabs.io/pricing for the latest information.
Generated MP3 Plays 0:00 / No Audio

If Mission Control reports that TTS generation succeeded but the resulting MP3 file is silent or shows a duration of 0:00, try the following:

  1. Check the text input. If the text is empty or contains only whitespace/special characters, ElevenLabs may return an empty audio payload.
  2. Check your ElevenLabs credits. Some edge cases return a 200 OK response with an empty audio body when credits are exhausted, rather than a proper error.
  3. Try a different voice. The default voice is "Roger" (a premade, free-tier compatible voice). If you have selected a custom or cloned voice that was deleted from your ElevenLabs account, the API may silently fail.
  4. Check the file in Finder. Navigate to the app's TTS output directory and check if the file has a non-zero file size. Files under 1 KB are almost certainly empty.
  5. Restart the app and try again. In rare cases, a stale HTTPS connection can cause truncated downloads.
Where are TTS files stored?
Generated MP3 files are saved to the app's internal tts-output directory within your Electron userData folder. You can find them in the Media Library or access them via Finder at ~/Library/Application Support/ovadeus/tts-output/.
Media Processing

Transcription

How YouTube Transcription Works

The YouTube Transcribe agent extracts text from YouTube videos using a multi-strategy approach:

Strategy 1: Caption Extraction (free, no API key needed)

The agent first attempts to pull existing captions/subtitles directly from YouTube. It tries multiple YouTube InnerTube API client contexts (Android, iOS, TV, Web) and a direct timedtext endpoint. If the video has captions — auto-generated or manual — this method is fast and free.

Strategy 2: Python youtube-transcript-api (fallback)

If the InnerTube approach fails, the agent tries a Python-based extraction script as a secondary caption fallback. This requires python3 to be available on your system (pre-installed on macOS).

Strategy 3: Whisper Audio Transcription (final fallback)

If no captions exist at all, the agent downloads the video's audio stream and sends it to OpenAI's Whisper API for speech-to-text. This requires an OpenAI API key and will incur a small cost.

Tip
Most videos have auto-generated captions, so Strategy 1 succeeds the vast majority of the time at no cost. Whisper is only used as a last resort.
Common YouTube Transcription Errors

"Could not extract video ID"

The URL you pasted is not a recognized YouTube format. Supported formats include:

  • https://www.youtube.com/watch?v=XXXXXXXXXXX
  • https://youtu.be/XXXXXXXXXXX
  • https://youtube.com/shorts/XXXXXXXXXXX

"No captions available" + no OpenAI key

The video has no captions (neither auto-generated nor manual), and you do not have an OpenAI API key configured for Whisper fallback. Either add an OpenAI key in Settings, or try a different video that has subtitles.

"Too many redirects" or timeout errors

These are typically transient network issues. Wait a moment and try again. If persistent, check your internet connection or try a VPN — some ISPs or networks throttle YouTube API requests.

"Python output parse error"

The Python fallback script failed. Ensure python3 is installed and the youtube-transcript-api pip package is available. Run pip3 install youtube-transcript-api in Terminal to install it.

How PDF Transcription Works

The PDF Transcribe agent extracts readable text from PDF files using a two-tier approach:

Tier 1: pdf-parse (fast, local, free)

The agent first uses Mozilla's pdf.js engine (via the pdf-parse library) to extract embedded text. This works for all standard PDFs with selectable text and properly handles Unicode, ligatures, and most font encodings.

Tier 2: Claude Vision OCR (fallback for scanned PDFs)

If Tier 1 fails or returns very little text (e.g., the PDF contains scanned images rather than embedded text), the agent automatically falls back to sending the pages to Claude as images for OCR. This requires a Claude API key and incurs a small cost per page.

Limits

  • Maximum file size: 20 MB
  • Maximum pages: 50
PDF Shows Garbled or Corrupted Text

Some PDFs produce garbled output (random characters, missing letters, or encoding artifacts). This usually happens because:

  • Custom font encoding: The PDF uses a proprietary or subset font that maps characters to non-standard Unicode points. The pdf-parse library does its best, but some fonts are unresolvable.
  • Scanned document with partial OCR: The PDF has an OCR layer that was poorly generated, resulting in gibberish.
  • Password-protected PDF: The extraction library cannot read encrypted content.

Solutions

  1. Let Claude OCR handle it. If you have a Claude API key configured, the agent will automatically fall back to vision-based OCR when the text extraction looks garbled (under 20 characters). If it is not triggering automatically, the extracted text may be just long enough to pass the threshold. Try re-running the agent on the specific pages that are garbled.
  2. Re-export the PDF. Open the PDF in Preview (macOS), go to File > Export as PDF, and save a new copy. This sometimes fixes encoding issues.
  3. Use a dedicated OCR tool first. Tools like Adobe Acrobat's OCR or macOS's built-in text recognition can produce a cleaner text layer before feeding the PDF into Mission Control.
Audio File Transcription (Whisper)

The Audio Transcribe agent sends local audio files to OpenAI's Whisper API for speech-to-text conversion.

Requirements

  • An OpenAI API key with billing enabled.
  • Supported audio formats: .mp3, .wav, .m4a, .aac, .flac, .ogg, .aiff
  • Maximum file size supported by Whisper: 25 MB. For larger files, split them first using a tool like Audacity or QuickTime.

How to use

  1. Navigate to the Agents Library and find Audio Transcribe.
  2. Click Run and select your audio file from the file picker. The agent looks in ~/Downloads, ~/Documents, and ~/Music.
  3. Wait for the transcription to complete. The result will be saved to the Media Library.
Cost
Whisper API costs approximately $0.006 per minute of audio. A one-hour podcast costs roughly $0.36.
Automation

Agents

What Are Agents?

Agents are AI-powered automations that perform specific tasks on your behalf. Each agent has a defined purpose, required permissions, and optional inputs. You can think of them as specialized assistants that run inside Mission Control.

Agent types

  • Built-in agents — Ship with the app. Includes Gmail Summary, Daily Planner, Research Pulse, YouTube Transcribe, PDF Transcribe, Audio Transcribe, Text to Speech, Desktop Cleanup, Probe Generator, File Organizer, and Gmail Spam Audit.
  • Custom agents — Agents you create using the Agent Builder. Define behavior with natural language prompts.
  • Community agents — Agents shared by the BGP community that you can install from the Agents Library.

Running an agent

  1. Go to the Agents Library from the sidebar.
  2. Find the agent you want and click Run.
  3. If the agent requires input (like a URL or file), you will be prompted to provide it.
  4. Results appear in the Run View, and outputs are saved to the appropriate location (Media Library, Brain, etc.).

Enabling and disabling

Each agent has an enable/disable toggle. Disabled agents will not appear in scheduled runs or the quick-run menu, but they remain available in the Agents Library if you want to re-enable them later.

Desktop Cleanup Agent

The Desktop Cleanup agent organizes files on your macOS Desktop into categorized folders, reducing clutter instantly.

Categories

  • _Images — .png, .jpg, .jpeg, .gif, .svg, .webp, .ico, .bmp, .tiff, .heic, .heif
  • _PDFs — .pdf
  • _Docs — .doc, .docx, .xls, .xlsx, .ppt, .pptx, .txt, .csv, .rtf, .pages, .numbers, .key
  • _Videos — .mp4, .mov, .avi, .mkv, .wmv, .webm, .m4v
  • _Audio — .mp3, .wav, .m4a, .aac, .flac, .ogg, .aiff
  • _Folders — Any existing folders on your Desktop (except the category folders themselves) are moved here.
  • _Misc — Everything else that does not match the above categories.

Safety features

  • The agent asks for explicit permission via a system dialog before moving any files.
  • If a file with the same name already exists in the destination folder, a numbered suffix is added (e.g., report (1).pdf).
  • The agent never deletes files — it only moves them.
  • A summary of all moved files is saved to the Brain for future reference.
No API key required
This agent runs entirely locally and does not require any API keys or internet connection.
Text to MP3 Agent

The Text to MP3 (Text to Speech) agent converts written text into natural-sounding speech audio using the ElevenLabs API.

How to use

  1. Ensure your ElevenLabs API key is configured in Settings.
  2. Go to Agents Library and run Text to Speech.
  3. Enter or paste the text you want converted.
  4. Optionally select a voice from the dropdown (defaults to "Roger").
  5. Click Run. The generated MP3 will appear in the Media Library.

Voices

Mission Control fetches your available voices from ElevenLabs. Free-tier accounts have access to a selection of premade voices. Paid plans unlock voice cloning and additional premium voices.

Research Pulse Agent

The Research Pulse agent researches your passion topics and returns concise summaries of recent developments, discoveries, and conversations happening in your areas of interest.

Requirements

  • A Claude API key (used for summarization and synthesis).
  • An active internet connection (the agent fetches information from the web).

How it works

  1. The agent reads your configured interests and research topics from your profile.
  2. It searches for recent content, news, and discussions related to those topics.
  3. Claude synthesizes the findings into a structured summary.
  4. Results are saved to the Research Feed and the Brain.

Research Pulse is tagged as a "morning" agent and works well as part of a daily routine alongside the Daily Planner and Gmail Summary.

The Daily Planner creates a personalized daily plan by combining signals from your Gmail inbox, calendar, habits, and Brain context.

Requirements

  • A Claude API key.
  • Gmail connected (for email context).

What it produces

A structured daily plan that typically includes:

  • Priority tasks extracted from recent emails.
  • Follow-up reminders for emails that need responses.
  • Time-blocked suggestions based on your patterns.
  • Reflection prompts tied to your Belief Genome dimensions.
Self-Reflection

BGP Reflections

What Is BGP Reflections?

BGP Reflections is the self-reflection layer of Mission Control. It provides a structured framework for examining your beliefs, values, and perspectives over time. Rather than a personality test with fixed results, it is a living system that evolves as you interact with it.

The core loop is simple: the app presents you with probes (thought-provoking questions), you respond honestly, and the system maps your responses to your Belief Genome — a multi-dimensional profile of your worldview.

Understanding Your Belief Genome

Your Belief Genome is a structured representation of your beliefs across multiple dimensions. Think of it as a map of your inner landscape — not to judge or categorize, but to help you understand yourself more clearly.

How it works

  • Each response you give to a probe is analyzed and mapped to one or more dimensions (e.g., "epistemology," "ethics," "aesthetics," "identity," "purpose").
  • Over time, patterns emerge that reveal your tendencies, tensions, and growth areas.
  • The Belief Genome page visualizes these dimensions and shows how they shift over time.

Privacy

All Belief Genome data is stored locally on your machine. No responses are sent to BGP servers. The only external call is to Claude for analysis, and that is done via your own API key with Anthropic's standard data retention policies.

How Probes Work

Probes are the fundamental unit of interaction in the BGP Reflections system. Each probe is a carefully crafted question or prompt designed to surface your beliefs about a specific topic or dimension.

Probe types

  • Generated probes — Created by the Probe Generator agent using Claude, personalized based on your existing genome and areas that need more data.
  • Curated probes — Pre-written probes from the BGP probe bank that cover foundational dimensions.

Responding to probes

There are no right or wrong answers. Write as much or as little as you like. The system works best with honest, reflective responses rather than short yes/no answers. Each response is tagged with the relevant dimension(s) and saved to your Brain for long-term context.

Dimension tagging

Each probe targets one or more specific dimensions. This precise tagging ensures that your responses contribute to the right part of your Belief Genome rather than being spread across unrelated areas.

What Does "Confidence" Mean?

In the Belief Genome system, Confidence does not measure how sure you are of your beliefs. Instead, it represents how confident the system is in its mapping of your beliefs for a given dimension.

Factors that increase confidence

  • More responses — The more probes you answer in a dimension, the more data the system has to work with.
  • Consistency — If your responses are internally consistent, confidence rises.
  • Recency — Recent responses carry more weight than older ones.

What low confidence means

A low confidence score simply means the system needs more data. It might indicate that you have not answered many probes in that dimension, or that your responses show a wide range of perspectives (which is perfectly healthy — it just means the map is harder to draw).

Tip
Do not try to "raise" your confidence score by giving uniform answers. The goal is authentic self-reflection, not high numbers. A low confidence score in a dimension is an invitation to explore that area more deeply.
Interface

Dashboard & Widgets

Dashboard Overview

The Dashboard is your home screen in Mission Control. It displays customizable widgets over a fullscreen background, with an intelligent idle-fade feature that turns the app into a gorgeous ambient display when you are not actively using it.

Key features

  • Widget grid — Shows your active widgets (clock, weather, inbox summary, recent runs, etc.).
  • Idle fade — After 30 seconds of no mouse movement, widgets and overlays fade out to reveal the full background. Move your mouse to bring them back.
  • Quick actions — The top-right buttons give you access to Settings, background options, and Peek mode.
Background Options

Mission Control supports multiple background types for the Dashboard:

Unsplash Photos

Dynamic, high-resolution photos from Unsplash. The app fetches a new photo on each launch or at a configurable interval. You can set a topic or keyword to influence the photo selection.

My Photos

Use your own photos as the background. Select a folder on your Mac, and the app will cycle through the images within it.

Video

Set a local video file as a looping background. Supports .mp4 and .webm formats. Works beautifully with the idle-fade feature for an ambient display effect.

Solid Color

A simple solid color background. Useful for a clean, minimal look or for reducing distractions.

Tip
A semi-transparent dark overlay is applied over backgrounds for widget readability. This overlay fades out along with the widgets when idle-fade activates, giving you the full-brightness photo/video experience.
Organizing and Resizing Widgets

Widgets on the Dashboard can be rearranged and resized to fit your workflow:

  • Drag to rearrange — Click and hold a widget header, then drag it to a new position in the grid.
  • Resize — Some widgets support resizing. Look for a resize handle in the bottom-right corner of the widget.
  • Show/hide — Toggle widget visibility from Settings or the widget management panel.

Widget layout is saved automatically and persists across app restarts.

Peek Mode

Peek mode lets you quickly glance at your Dashboard without fully switching to the app. Hover over the Mission Control icon in the bottom-right corner of your screen (Dock area) to activate a translucent, overlay-style preview.

Peek mode is read-only — it shows widget data but does not allow interaction. Click anywhere on the overlay to dismiss it, or click the main app icon to switch to the full app.

Intelligence

Brain / Memory

What Is the Brain?

The Brain is Mission Control's persistent memory layer. It stores context, insights, and records from everything that happens in the app — agent runs, reflections, research findings, file operations, and more.

Why it matters

The Brain gives agents long-term context. When the Daily Planner creates your morning plan, it can reference past agent runs, previous research summaries, and your recent Belief Genome activity. This makes each agent run smarter and more personalized over time.

How data gets in

Brain entries are created automatically by agents after each run. You do not need to manually add entries (though you can via the Memory page). Examples:

  • The Desktop Cleanup agent saves a summary of which files were moved where.
  • The Research Pulse agent saves research summaries and key findings.
  • The Gmail Summary agent saves a digest of important emails.
  • Probe responses are stored as reflections linked to Belief Genome dimensions.
Understanding Brain Entries

Each Brain entry consists of:

  • Type — The category of the entry (e.g., "agent-run", "reflection", "research", "file-op").
  • Content — The actual text content or summary.
  • Source — Which agent or feature created the entry.
  • Timestamp — When the entry was created.
  • Tags — Optional tags for organization and filtering.

Browsing the Brain

The Brain page (accessible from the sidebar) displays entries in reverse chronological order. You can filter by type, search by keyword, and expand individual entries to see the full content.

The Memory page

The Memory page is a separate, more structured view that lets you manually create, edit, and organize memory entries. Think of the Brain page as an activity log and the Memory page as a notebook.

Help

Troubleshooting

App Won't Start

If Mission Control fails to launch or crashes immediately on startup, try these steps in order:

  1. Restart your Mac. A simple reboot resolves many Electron-related launch issues.
  2. Check macOS Gatekeeper. Go to System Settings > Privacy & Security and see if there is a blocked app notice. Click "Open Anyway" if prompted.
  3. Reset the app's data. If the app is crashing due to corrupted preferences, you can clear the stored data. In Finder, press Cmd + Shift + G and navigate to ~/Library/Application Support/ovadeus/. Rename the folder to ovadeus-backup and relaunch the app. This will start with fresh defaults while preserving your old data as a backup.
  4. Check for macOS updates. Ensure you are running macOS 12 (Monterey) or later.
  5. Launch from Terminal. Open Terminal and run:
    /Applications/BGP\ Mission\ Control.app/Contents/MacOS/BGP\ Mission\ Control
    This will show any error messages in the console that can help diagnose the issue.
  6. Reinstall the app. Delete the app from Applications and reinstall from the latest distribution.
API Key Not Working

If an agent fails with an authentication or "invalid key" error, check the following:

  1. Verify the key format.
    • Claude (Anthropic) keys start with sk-ant-
    • OpenAI keys start with sk-
    • ElevenLabs keys are alphanumeric strings (no prefix)
  2. Check for extra whitespace. Copy-pasting keys sometimes introduces leading or trailing spaces. Open Settings, clear the field, and paste the key again carefully.
  3. Confirm billing is active. Most API providers require an active payment method or credit balance. A valid key with no billing will be rejected.
  4. Check if the key was revoked. Log in to the provider's dashboard and verify the key is still active and has not been rotated.
  5. Check rate limits. If the key works sometimes but not always, you may be hitting rate limits. Wait a minute and try again.
ElevenLabs specifically
Remember that ElevenLabs has both account-level credits and per-key quotas. See the detailed breakdown above.
Features That Work Offline vs. Online

Works offline (no internet required)

  • Dashboard, widgets, and background (if using local photos/video/solid color)
  • Desktop Cleanup agent
  • PDF Transcription (Tier 1 — local text extraction only; OCR fallback requires internet)
  • Brain and Memory browsing
  • Media Library browsing and playback
  • Belief Genome viewing (reading existing data)

How to Check for Updates

Mission Control does not currently auto-update. To check for a new version:

  1. Visit the official BGP website at beliefgenomeproject.org.
  2. Check the Downloads or Releases section for the latest version number.
  3. Compare it with your installed version. You can find your version in Settings at the bottom of the page or in the app's About dialog (accessible from the macOS menu bar: BGP Mission Control > About).
  4. If a newer version is available, download the new .dmg and install it over your existing installation. Your settings and data will be preserved (they live in ~/Library/Application Support/ovadeus/, not inside the app bundle).
Note
Auto-update functionality is planned for a future release. For now, check the website periodically or join the BGP community for update announcements.
