# Belief Genome Project — Participant Reflection

**A meta-probe session about the session you just completed.**

You just spent time answering probes about your beliefs. This short form does the same thing — but the dimension being explored is *your experience of the tool itself*. Each statement is a probe. Read it, sit with it for a moment, and mark how true it feels for you right now, using the same scale you used in the app.

Some statements may feel like the inverse of one you saw earlier. That's intentional — it lets us measure the coherence of your reflections the same way the tool measures the coherence of your beliefs. Answer each one fresh.

**Time:** about 12 minutes.

---

## How to answer

For every numbered probe below, mark one of:

`AF` Absolute False  ·  `F` False  ·  `B` Balanced  ·  `T` True  ·  `AT` Absolute True  ·  `?` Uncertain

(Same scale as the app. "Uncertain" is a real, valid answer — use it whenever neither pole feels true.)

# Researcher's coherence key *(do not include on participant copy)*

The following probes form **framing pairs** — canonical and inverted statements about the same underlying belief. A coherent respondent will answer them as opposites (one True/AT, the other False/AF). When both poles are answered the same way, that is a coherence break worth examining — it may signal ambivalence, satisficing, or that the dimension itself is not yet stable for this person.

| Pair | Canonical | Inverted | Dimension |
|------|-----------|----------|-----------|
| P1 | 1.1 (probes felt meaningful) | 1.5 (probes felt like a chore) | Probe experience |
| P2 | 2.1 (encountered new beliefs) | 2.5 (only confirmed what I knew) | Self-discovery |
| P3 | 3.2 (visualizations revealed patterns) | 3.5 (visualizations were decoration) | Visualizations |
| P4 | 4.1 (left me curious) | 4.6 (left me depleted) | Emotional resonance |
| P5 | 4.2 (felt safe being honest) | 4.5 (held back, felt watched) | Emotional resonance |
| P6 | 5.4 (earned a place in my reflection) | 5.5 (one-time curiosity, no role) | Usefulness |
| P7 | 6.3 (I have control over my responses) | 6.4 (tool takes more than it gives) | Trust |

**Suggested coherence scoring** (per pair, after mapping AF=0, F=2, B=4, T=6, AT=8, ?=4):

`coherence = | canonical_score + inverted_score - 8 |`

Lower values (closer to 0) mean the participant answered as a true mirror pair. Higher values (toward 8) mean the participant gave the same answer to both poles — a coherence break. Aggregate across pairs to get a per-participant coherence score on the *meta-experience* itself, which tells you how settled vs. emergent their feelings about the tool are.

**Unpaired probes** in dimensions 1–6 are single-pole signal items, useful as direct measures.

**Open reflections** (R1–R6) are narrative probes — read for themes rather than scoring.

**Quantitative anchors** (S1–S3) plus the NPS in S3 are kept in classical format because they measure facts (count, time) and an industry-standard advocacy score that is directly comparable across products.
